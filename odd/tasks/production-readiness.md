## Recommended resolutions (decision rows to record)

| ID | Finding | Resolution |
|---|---|---|
| R1 | Absence and MARCA_FALTANTE jobs have no date bound | Jobs only consider jornadas whose local date is within the last 7 days; older jornadas are never flagged automatically |
| R2 | Past dates accepted and pushed; reactivation backlog pushes at once; first deploy pushes old days | Deviations are still recorded, but a push is only enqueued when the deviation is detected less than 2 h after its due instant |
| R3 | Reactivating an employee creates SIN_INGRESO for days while inactive | Covered by R1 + R2: at most 7 days are flagged, none pushed; the ADMIN cancels them if needed |
| R4 | Moving a site center keeps declared jornadas on the old center (changes D-20261030-02) | Moving the center also updates the snapshot of jornadas of that site that are `NO_INGRESO` without marks and dated today or later; started jornadas keep theirs |
| R5 | New passwords limited to 72 bytes by BCrypt while the API documents 12–256 | Validate 12 characters to 72 UTF-8 bytes with code `PASSWORD_TOO_LONG`; existing hashes untouched |
| R6 | Audit history cap keeps the oldest 500 entries | Keep the newest 500, still returned in chronological order, with a `truncated` flag |
| R7 | Fixed-offset zone such as `-03:00` accepted for a site | Only region IANA ids (`ZoneRegion`) are accepted |
| R8 | Single and bulk declaration disagree on an inactive template | Both answer `TEMPLATE_INVALID` |
| R9 | Declaration ignores `employee_sites` | Declaring a jornada for an employee not assigned to that site answers 409 `EMPLOYEE_NOT_IN_SITE` |
| R10 | `login_throttles` rows never purged | The privacy job purges rows older than one day, like `login_ip_throttles` |
| R11 | Accepted as is, documented: 5 concurrent correct logins of one DNI answer 429; ADMIN forgotten EGRESO beats a later real one (the ADMIN voids it); DST shift lasts its wall-clock span; gap/overlap resolved like java.time; SALUD correction restarts the 90 days; window with only 404/410 subscriptions is SENT; no endpoint deactivates a template; malformed Idempotency-Key 422; rejected key reusable; trusted proxy without usable address 422; DELETE foreign subscription 204; lunch turned into egress blocks VUELTA; failure window inclusive at its end | Documented in ESPECIFICACION.md, no code change |
